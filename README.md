# Pretix Dashboard View
This is a small widget showing remaining tickets available for an audio event; this information would otherwise be trapped behind a login into our ticket providing app, but we want it to be viewable on an existing dashboard along with our other metrics.

<img width="584" height="282" alt="image" src="https://github.com/user-attachments/assets/1be3647a-2d50-4b53-bf31-ad1c02afd8e7" />

Having this for quick reference meant that the whole team could be aware of our tickets remaining status; we used a distributed method of promotion so this let us communicate ticket availability or not in a decentralized fashion.
